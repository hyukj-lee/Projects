# 2026년 천안시 AI·데이터 기반 정책 아이디어 경진대회

- 주제: 최적 입지분석을 통한 천안시 생활서비스 취약지역 개선
- 팀원: 심현석, 이성진, 이혁진

천안시를 500m 격자로 세분화하여 생활서비스 공급 수준의 분포를 파악하고, 생활서비스 취약지역에 배치할 생활시설의 후보 입지를 탐색한 데이터 분석 프로젝트입니다. 15분 도시의 생활권 개념을 참고하여, 주민이 거주하는 격자에서 생활시설에 접근할 수 있는 공간적 범위를 정의하고 지역 유형별 정책 방향을 제안합니다.

## 분석 방법

- **데이터 통합**
  - 생활복지, 상업, 의료, 교육, 여가 관련 시설 데이터를 통합
  - 주소 기반 시설의 위도·경도 보완 및 격자 단위 배정

- **500m 격자 기반 공간 데이터 구축**
  - 인구·세대·생활시설 정보를 500m 격자 단위로 집계
  - 주변 1,000m 이내 격자의 인구와 시설을 거리 가중 방식으로 반영

- **생활지수 및 인구수요지수 산출**
  - 생활복지, 상업, 의료, 교육, 여가의 5개 생활지수 산출
  - 인구와 세대수를 활용한 인구수요지수 산출
  - 시설 수는 `log1p` 변환과 표준화를 거쳐 지수화

- **K-Means 클러스터링**
  - 인구수요지수와 5개 생활지수를 활용하여 격자 단위 공간 유형 분류
  - 격자별 클러스터링 결과를 인구 기준으로 집계하여 읍면동별 대표 클러스터 도출

- **LSCP(Location Set Covering Problem) 최적 입지분석**
  - 기존 시설로 커버되지 않는 인구 거주 격자를 미충족 수요 격자로 정의
  - 각 생활지수별로 모든 미충족 수요 격자를 1,000m 이내에서 커버하는 최소 후보 입지 탐색
  - 동일한 최소 입지 수의 해가 여러 개인 경우, 미충족 인구를 더 많이 커버하는 입지를 우선 선택

- **시설 배치 사후분석**
  - LSCP에서 선정한 입지 중 일부에 생활시설을 설치하는 시나리오 구성
  - 시설 배치 후 생활지수와 격자별 클러스터를 재산출
  - 읍면동별 대표 클러스터 변화와 생활지수 개선 폭을 비교하여 단계적 정책 우선순위 검토

## 분석 내용

1. 천안시 생활시설과 인구 데이터를 통합하여 500m 격자 단위 분석 데이터셋을 구축한다.
2. 격자별 인구수요와 생활서비스 수준을 산출하여 인구수요지수 및 생활지수를 산출한다.
3. 생활서비스가 상대적으로 부족한 클러스터를 도출하고, 읍면동별로 대표 유형을 분류한다.
4. 생활서비스 취약 지역에 생활시설을 새로 배치할 입지 후보를 개수가 최소가 되도록 탐색한다.
6. 제한된 시설 배치 비율별 사후분석을 통해 생활지수 개선과 대표 클러스터 변화 가능성을 비교한다.
7. 분석 결과를 바탕으로 고정형 시설, 복합 생활거점, 이동형·순회형 서비스 등 지역 유형별 정책 방향을 제안한다.

## 주요 산출물

- 통합 생활시설 데이터 및 지오코딩 결과
- 500m 격자별 인구·시설 통계 데이터
- 격자별 및 읍면동별 클러스터링 결과
- 생활지수별 LSCP 후보 입지 결과
- 시설 배치 시나리오별 사후분석 결과
- 클러스터 지도, 입지분석 지도, 생활시설 분포 시각화
